# Part 6. Trends — 최근 1년 심화

> 각 트렌드가 **무엇인지**를 깊게 다룬다. **어느 단계에서 어떻게 쓰는지**는 Part 2~4 각 페이지의 "최신 트렌드 적용" 섹션에 있다. 두 곳은 서로 링크한다.

## 분류 기준

- **기간**: 2025-10 ~ 2026-10에 각광받기 시작했거나 성격이 크게 바뀐 것만. 그 이전 것은 Part 1 기반 지식으로 서술
- **레이더 위치**: 채택 / 시험 / 관찰 / 보류. `[검증]` 또는 `[실측]` 없이는 채택으로 올리지 않는다 ([작성 가이드](../_meta/writing-guide.md) 5절)
- **필수 주제 ★**: 온톨로지, 뉴로심볼릭, 결정 모델은 이 위키가 반드시 다루는 주제. 모든 관련 단계 페이지에서 적용 여부를 명시한다

## 결정 모델 두 접근의 요점 비교 (상세는 전용 페이지)

| 항목 | TypeSafe AI Jev | OpenAI Decisions API | 검증 수준 |
|---|---|---|---|
| 공개 | 2026-09-15 얼리액세스 | 2026-09-29 DevDay 발표(제한 프리뷰) → 2026-10-06경 퍼블릭 베타 | `[2차]` — 소스 간 날짜 충돌 |
| 모델 성격 | 결정 전용 모델, 비자기회귀, 단일 패스, 병렬 샘플링 + RLCD(보정 결정 강화학습) 주장 | 범용 생성 모델(gpt-6-luna)의 출력을 제약한 엔드포인트(`POST /v1/decisions`). 별도 결정 전용 모델 아님 | `[벤더]` `[2차]` |
| 입력 | 상태(텍스트/JSON) + 코드로 정의한 타입드 질문 | 컨텍스트(텍스트·이미지) + 개발자 정의 질문 | `[벤더]` |
| 출력 | 선택 / 점수 / 예·아니오 + 보정 확률. 텍스트 없음 | 조건 참 확률 / 선택지 중 선택 / 루브릭 점수 | `[벤더]` |

## 트렌드를 "채택"으로 올리는 절차

1. 전용 페이지의 "벤더 주장 vs 검증된 사실" 표를 채운다
2. 우리 데이터(특히 한국어)로 `[실측]`을 만든다. 시나리오 페이지에 PoC로 기록
3. 적용 단계 페이지의 비교표에 행으로 추가하고 "적합/부적합 상황"을 채운다
4. 레이더 위치를 바꾸고 CHANGELOG에 기록
