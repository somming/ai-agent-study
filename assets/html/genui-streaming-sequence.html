Generative UI 스트리밍 시퀀스 — 요청 → 텍스트 델타 → 툴 호출 → 상태 패치 → UI → 승인 → 검증 → 실행 → 완료

한 run이 흐르는 순서. 메시지를 클릭하면 해당 위키 페이지로, 참여자 헤더를 클릭하면 그 참여자를 다루는 페이지로 이동합니다. 가로선 위의 동그라미는 AG-UI 이벤트 스트림(SSE)을 거친다는 뜻입니다.
